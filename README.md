# Ecma-script

Este proyecto aborda el diseño visual **disponible en movil y PC** sobre informaciòn de**Ecma scipt en JS**. Está desarrollado únicamente con **HTML y CSS**
> ⚠️ **Importante**: Este sitio está diseñado tanto para PC como para moviles

## 🧩 Características

El proyecto cuenta con las siguientes pantallas implementadas:

- **Login (`index.html`)**: Pantalla de inicio .
- **Contenido(`contenido.html`)**: Muestra informacion sobre Ecma Script
- **Codigo (`codigo.html`)**: Muetra ejemplos.
